# ひらがじゃん

ひらがな牌を集めて単語を作る、麻雀風の対戦単語ゲームです。
スマホや PC のブラウザから、友達と同じルームに入って遊べます。

## 遊ぶ

[ひらがじゃんを開く](https://shitake-zense.github.io/hiragajan/)

アプリを開いたら、名前を入れてルームを作るか、友達から教えてもらったルーム ID で参加してください。

## 遊び方

1. 代表者が「ルームを作成する」を押します。
2. 表示された 6 桁のルーム ID を一緒に遊ぶ人へ伝えます。
3. 参加する人は同じリンクを開き、名前とルーム ID を入力します。
4. 人数がそろったら、ホストがゲームを開始します。
5. ひらがな牌を引いたり捨てたりしながら、単語を作って点数を獲得します。

## どんなゲーム？

- 2〜4人で遊べます。
- 1 / 3 / 5 ラウンドから選べます。
- ひらがな牌を組み合わせて単語を作ります。
- ポン、カン、立直、ロン、ツモがあります。
- ドラ、風、役ボーナスで点数が増えます。
- ラウンドごとの結果と累計順位が表示されます。

麻雀の雰囲気を借りた単語ゲームなので、麻雀を知らなくても雰囲気で遊べます。

## 操作の流れ

自分の番になったら、手牌を見て行動します。

- 牌を引く
- 不要な牌を捨てる
- 作れそうな単語があればあがる
- 条件が合えばポン、カン、立直を使う

画面に出るボタンを押して進めれば大丈夫です。

## うまく入れないとき

- ルーム ID が 6 桁で正しいか確認してください。
- すでにゲームが始まっているルームには入れない場合があります。
- 定員に達しているルームには入れません。
- 画面が止まったように見えるときは、ページを再読み込みしてから入り直してください。
- 別のブラウザやシークレットウィンドウで開くと直ることがあります。

## 注意

このゲームは友達同士で遊ぶための身内向けミニゲームです。

- 辞書チェックはまだ厳密ではありません。
- 強い不正対策は入っていません。
- 通信には Firebase / Firestore を使っています。
- 予告なくルールや点数が変わることがあります。

## 開発者向け

このリポジトリはビルド不要の静的サイトです。
GitHub Pages ではルートの `index.html` から `public/index.html` に移動します。

ローカルで確認する場合:

```bash
cd public
python -m http.server 8080
```

主なファイル:

- `public/index.html`: ロビー画面
- `public/game.html`: ゲーム画面
- `public/js/lobby.js`: ルーム作成 / 参加
- `public/js/game.js`: ゲーム進行
- `public/js/utils.js`: 牌、役、点数まわり
- `public/js/firebase-config.js`: Firebase 設定

### 古いルームの自動削除（TTL）

ルーム作成時に `expireAt`（作成から7日後）フィールドを書き込んでいます。
Firestore の TTL ポリシーを一度だけ設定すると、失効したルームが自動削除されます。

```bash
gcloud firestore fields ttls update expireAt \
  --collection-group=rooms \
  --enable-ttl \
  --project=hiragajan-f3887
```

または Firebase コンソール → Firestore →「TTL」から `rooms` コレクションの
`expireAt` フィールドを有効化してください。
